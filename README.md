# Artificial Intelligence Learning Journey - 5 Experiments + Capstone Project

A comprehensive hands-on learning path to master AI concepts using Python. This repository contains 5 progressive experiments and one cutting-edge capstone project to build your AI expertise from fundamentals to advanced applications.

## 📚 Curriculum Overview

### **Experiment 1: Linear Regression - Understanding the Basics**
- **Concept**: Supervised learning, model training, and predictions
- **What you'll learn**: How algorithms learn from data to make predictions
- **Tools**: NumPy, Scikit-learn, Matplotlib
- **Duration**: 1-2 hours
- **[Code & Tutorial →](./Experiment_1_Linear_Regression/)**

### **Experiment 2: Logistic Regression - Classification Problems**
- **Concept**: Binary classification, probability predictions, decision boundaries
- **What you'll learn**: How to classify items into categories
- **Tools**: Scikit-learn, Pandas, Matplotlib
- **Duration**: 1-2 hours
- **[Code & Tutorial →](./Experiment_2_Logistic_Regression/)**

### **Experiment 3: Decision Trees & Random Forests - Ensemble Learning**
- **Concept**: Tree-based models, ensemble methods, feature importance
- **What you'll learn**: How multiple models work together for better predictions
- **Tools**: Scikit-learn, Pandas, Seaborn
- **Duration**: 2-3 hours
- **[Code & Tutorial →](./Experiment_3_Decision_Trees/)**

### **Experiment 4: Neural Networks - Introduction to Deep Learning**
- **Concept**: Artificial neurons, layers, backpropagation, activation functions
- **What you'll learn**: Fundamentals of deep learning and neural network architecture
- **Tools**: TensorFlow/Keras, NumPy, Matplotlib
- **Duration**: 2-3 hours
- **[Code & Tutorial →](./Experiment_4_Neural_Networks/)**

### **Experiment 5: Clustering & Unsupervised Learning**
- **Concept**: K-Means, hierarchical clustering, dimensionality reduction
- **What you'll learn**: Finding patterns in unlabeled data
- **Tools**: Scikit-learn, Pandas, Matplotlib
- **Duration**: 2-3 hours
- **[Code & Tutorial →](./Experiment_5_Clustering/)**

### **Capstone Project: Build a Multimodal AI Chat Application**
- **Concept**: Transformer models, embeddings, retrieval-augmented generation (RAG)
- **What you'll learn**: Combining latest AI technologies in a real-world application
- **Tools**: LangChain, OpenAI API, Vector databases, Flask
- **Duration**: 4-5 hours
- **[Code & Tutorial →](./Capstone_Project_AI_Chat/)**

## 🚀 Getting Started

### Prerequisites
- Python 3.8 or higher
- pip or conda package manager
- Basic understanding of Python programming
- A code editor (VS Code, PyCharm, Jupyter Notebook)

### Installation

```bash
# Clone the repository
git clone https://github.com/KashifKazmi91/Artificial-Intelligence.git
cd Artificial-Intelligence

# Create a virtual environment
python -m venv ai_env

# Activate virtual environment
# On Windows:
ai_env\Scripts\activate
# On macOS/Linux:
source ai_env/bin/activate

# Install required packages
pip install -r requirements.txt
```

## 🔍 What Each Experiment Teaches

### Experiment 1: Linear Regression
- **Problem**: Predict house prices based on features
- **Algorithm**: Linear regression with gradient descent
- **Key Learning**: How models fit data and make predictions

### Experiment 2: Logistic Regression
- **Problem**: Classify emails as spam or not spam
- **Algorithm**: Logistic regression with sigmoid function
- **Key Learning**: How probability-based classification works

### Experiment 3: Decision Trees & Random Forests
- **Problem**: Classify iris flowers by characteristics
- **Algorithm**: Decision trees and ensemble methods
- **Key Learning**: How trees make decisions and voting improves accuracy

### Experiment 4: Neural Networks
- **Problem**: Recognize handwritten digits (MNIST)
- **Algorithm**: Multi-layer perceptron with backpropagation
- **Key Learning**: How deep learning networks learn complex patterns

### Experiment 5: Clustering
- **Problem**: Segment customers for marketing
- **Algorithm**: K-Means clustering and hierarchical clustering
- **Key Learning**: Finding patterns in unlabeled data

### Capstone Project: AI Chat Application
- **Problem**: Build a conversational AI that understands context
- **Technologies**: Transformers, embeddings, vector databases, LLMs
- **Key Learning**: Integrating modern AI technologies in production
